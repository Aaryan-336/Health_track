# User Flows

## 1. Couple Connection

```text
User A creates account
-> Creates couple invite
-> Shares code/link
-> User B joins
-> Membership validated
-> Shared couple space created
```

## 2. Create Shared Goal

```text
Together tab
-> Create goal
-> Select category
-> Add title and target
-> Select shared
-> Both participants attached
-> Goal becomes active
```

## 3. Log Water

```text
Tap Add
-> Select Water
-> Enter amount
-> Save
-> Water total updates
-> Goal progress updates
-> Daily score recalculates
```

## 4. Send Cute Message

```text
Messages
-> New message
-> Write content
-> Select cute background
-> Send now or schedule
-> Notification created
-> Recipient receives push
-> Opening notification deep-links into full-screen message
```

## 5. Open When Letter

```text
Create letter
-> Select trigger
-> Write message
-> Select background
-> Save
-> Recipient sees available letter
-> Opens it
-> Open event recorded
```

## 6. Goal Completion

```text
Progress reaches target
-> Transaction completes
-> Goal marked completed
-> Celebration record created
-> Both users receive celebration
-> Animated completion screen appears
```
