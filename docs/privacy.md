# Privacy and Consent Architecture

# 1. Default Rule
Personal health and journal data is private by default.

# 2. Explicit Sharing
Sharing must be category-specific. Examples:
- Share completed workout event: optional
- Share water target completion: optional
- Share exact water quantity: separate permission
- Share mood category: optional
- Share journal entry: explicit per-entry action

# 3. Couple Dashboard
The couple dashboard should show shared data and voluntarily shared updates. It must not become a surveillance dashboard.

# 4. Mood Sharing
A mood entry can have:
- Private
- Share status only
- Share status plus optional note

The user chooses at the time of entry or through defaults they can later change.

# 5. Relationship End
When a relationship ends:
- Revoke future access immediately.
- Preserve each user's personal data.
- Apply product-defined rules to shared data.
- Stop scheduled partner notifications.
- Remove active push actions tied to the relationship.

# 6. Data Controls
Provide:
- View sharing settings
- Revoke sharing
- Delete account
- Export personal data where supported

# 7. AI Privacy
AI context must obey the same access rules as normal application screens.
