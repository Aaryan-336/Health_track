# UI/UX Design System

## Design Direction

The app should feel:
- Soft
- Romantic
- Playful
- Premium
- Personal
- Cutesy without feeling childish

Use the supplied visual references as inspiration for the overall pastel colour language, soft cards, rounded shapes, organic illustrations and layered depth.

## Visual Principles
- Large rounded cards
- Generous whitespace
- Soft gradients
- Organic blobs and progress shapes
- Subtle shadows
- Cute micro-interactions
- Emotionally warm copy

## Navigation

```text
Home | Goals | Add | Together | Profile
```

## Home
Show:
- Greeting
- Daily health score
- Today's water
- Habits
- Workout/activity
- Mood
- Active goals
- Partner update when consent exists

## Couple Dashboard
Show:
- Couple score
- Shared goals
- Couple streak
- Current challenge
- Latest encouragement
- Upcoming milestones

## Motion
Use motion for:
- Card entrance
- Progress completion
- Goal completion
- Message opening
- Celebration moments

Avoid excessive animation. Motion should feel soft and intentional.

## Accessibility
- Maintain readable contrast
- Do not rely only on colour for status
- Support reduced motion
- Use large tap targets
